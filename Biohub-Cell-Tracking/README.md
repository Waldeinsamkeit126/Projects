# Biohub — Cell Tracking During Development

Kaggle 细胞追踪比赛的本地实验归档，保存 Notebook、诊断结果、提交实验及相关工作文件。

## 归档入口

[2026-10-01 归档](archive-20261001-114519/) 包含 2,401 个原文件的路径与校验清单。归档采用按内容去重的存储方式，因此压缩包内的文件名是 SHA-256，而不是原始文件名。

- `manifest.json`：原相对路径、文件大小和 SHA-256。
- `archive-info.json`：合并后的 ZIP 校验值与分卷数量。
- `payload.zip.part*`：ZIP 的有序分卷。

## 恢复流程

1. 按文件名顺序以二进制方式拼接所有 `payload.zip.part*`，生成 `payload.zip`。
2. 对合并文件计算 SHA-256，与 `archive-info.json` 对照。
3. 将 ZIP 解压到新的临时目录。
4. 按 `manifest.json` 将哈希命名的文件复制到新恢复目录下的 `ArchivePath`，并逐文件核对 SHA-256。同一文件内容可能对应多个原路径。

不要直接把哈希文件改名后移走，否则同内容的其他原路径可能无法恢复。恢复时使用全新目录，避免覆盖已有文件。
