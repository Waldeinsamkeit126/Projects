# Kaggriculture V2 混合经济代理

生成日期：2026-08-02

## 线上反馈

- V1 `primary-v1-melon24` 已成功提交，首轮评分 `566.4`。
- 首轮 4 场均负。回放显示 V1 只经营作物，而线上对手早期铺设鸡舍、牧场并持续获得动物产品和肥料，形成复利优势。

## V2 的主要变化

- 农场约 35% 用于畜牧，65% 用于作物；畜牧组合适度偏向奶牛。
- 自动完成购买动物、建设鸡舍/牧场、拾取与放置、每日喂养、照料、收获产品和收集肥料。
- 提前储备饲料，避免动物因连续两天未喂养而逃跑。
- 根据蛋、奶、羊毛的实时价格和对手公开农场，减缓拥挤品类的扩张。
- 作物部分以甜瓜为主，并保留小麦/胡萝卜作为短周期现金流。
- 最后一天强制把工人库存送回仓库并清算。
