## V3 的核心变化

1. 养殖权重从鹅/牛/羊 `25%/45%/30%` 调整为 `8%/55%/37%`。
2. 同类动物拥挤惩罚从 `0.16` 降至 `0.06`，避免因为对手养牛而过度切换到低价值鹅群。
3. 第 0–17 天作物权重从甜瓜/胡萝卜/小麦 `86%/7%/7%` 调整为 `78%/8%/14%`，减少饲料净采购并增强早期现金流。
4. 保留 V2 的保守扩地条件。真实回放消融显示，强制提前购买第三块地会增加种子和雇工成本，平均收益反而下降。

## 验证结果

- V2 真实线上样本：21 场，13 胜 8 负，平均得分 `80,766.6`。
- V3 对相同 21 个种子、位置和对手动作的反事实回放：18 胜 3 负，平均得分 `91,255.8`。
- 相对 V2：平均自身得分 `+10,489.2`，平均对局优势 `+20,544.5`。
- 本地 V3 对 V2 双向赛：8 胜 0 负，平均优势 `+12,717.3`。
- V3 自博弈：8 场平均双方得分均为 `71,491.4`，平均优势为 `0`。
- 最慢单步：本地双向赛约 `62.5 ms`；真实回放压力测试约 `141.8 ms`，低于 Kaggle 的 1 秒限制。
