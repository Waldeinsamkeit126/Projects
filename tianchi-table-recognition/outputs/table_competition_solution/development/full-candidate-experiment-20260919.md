## 失败原因

第 118 题要求按顺序给出四个字段，其中两个字段分别包含多个科目。模型用嵌套数组表示这两个多值字段，本地直接值数组校验器拒绝了嵌套元素。不是鉴权、欠费、连接或 token 截断问题。

当前官网示例支持直接值数组，但未进一步解释“一个要求的字段本身有多个名称”时的序列化细节。因此，这一诊断证明模型输出与当前本地契约不一致，不能证明该答案在官方评测中一定错误。不能为了导出而静默放宽校验、机械展平、手工改答案或声称已修复。

这也说明原方案将单题格式失败视为整轮停止，会阻碍快速得到完整候选。改变停止策略需要向用户说明并取得同意；用户此前希望快速提交不自动撤销费用和停止边界。
