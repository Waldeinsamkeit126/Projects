## 改动边界

- `--check-full-coverage` 默认关闭，仅明确要求完整结构的 JSON 题适用。局部表头、否定完整恢复的题意优先排除；不明确时跳过。独立样例可提供 full/partial 范围元数据，正式问题不按题号补标签。
- 常规结构校验先检查正整数尺寸、坐标范围和不重叠，随后用精确整数面积检查网格完整性。最多返回 4 个缺口示例，不按行列数分配巨大矩阵。
- 空白格是合法格，不等于缺失格。网格缺口触发带原图的重新识别，不通过自动扩大跨度或填空来“修正”。保留初答与复核答案历史，仍使用 Qwen。
- `validateAnswer` 的原严格评估语义不变。新增推理阶段检查不通过改评分器制造提升，也不统一改写数值精度。
- 批量 JSON 解析修复也遵守 `--max-completion-tokens`，不再把较低配置抬到 16384。所有实际请求（含重试）计入同一个上限。
- 新代码和开关进入缓存身份；默认状态目录升级为 `state-reliable-v2`。旧记录、缓存和答案未删除。旧版三个源码备份在工作区 `work/coverage-backup-20260915/`，仅供差异审计，不是可直接运行的独立发行包。

覆盖完整只是必要条件。尺寸一起缩小但仍填满、文字错、错误地拆分或合并但面积守恒、定位了错误表格，都可能通过。保守的题意规则也可能漏掉某些完整结构题。不能将校验通过率称为识别准确率。
